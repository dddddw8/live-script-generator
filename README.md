# 直播话术智能生成器

> AI 驱动的直播带货话术生成工具，输入产品信息即可自动生成符合「痛点→背书→卖点→促单」结构的专业直播话术，内置违禁词检测与替换。

## 一、项目简介

### 解决什么问题

直播运营人员在日常工作中，**单品话术撰写耗时 1-2 小时**，且容易触碰平台违禁词导致直播间被处罚。本工具将话术撰写时间缩短至 **5-10 分钟**，并自动检测违禁词，大幅提升工作效率和合规安全性。

### 核心功能

1. **6步话术生成流程**：产品信息输入 → AI卖点分析 → 参数设置 → AI话术生成 → 违禁词检测替换 → 终版输出
2. **AI 信息完整性检查**：点击下一步时，AI 自动检查产品信息是否完整，缺失信息以交互式弹窗追问，并提供可点击的 AI 建议
3. **多模型交叉对比**：Claude 4.6 Sonnet + DeepSeek V3 + Qwen3 235B 三个模型同时生成话术，AI 自动评分推荐最优版本
4. **AI 智能违禁词检测**：先本地词库扫描（130+词），再 AI 分析语境排除误判（如"第一时间"不算违禁），支持手动添加自定义违禁词
5. **图片智能识别**：上传产品图片，AI（Qwen3 多模态模型）自动识别并生成结构化产品信息
6. **话术方法论**：内置 AIDA 模型、FABE 卖点原则、促单四大心理、话术品牌化三要素、十大话术类型等实战方法论
7. **灵活参数配置**：4 种话术风格 + AI 推荐选项、3 档字数、3 档闭环时间
8. **多格式下载**：支持 PDF、Word、HTML、Markdown、TXT 五种格式，支持自定义文件名
9. **历史记录管理**：自动保存到 localStorage，支持搜索、编辑、删除、下载
10. **首页演示动画**：自动播放的话术生成过程动画，5个阶段循环展示

### 使用流程

1. **输入产品信息**：选择产品类目（快捷填充），输入产品详情，可上传图片/文件让 AI 自动识别并生成结构化信息
2. **AI 信息检查**：点击下一步时 AI 自动检查，缺失信息弹窗追问（可点击 AI 建议快速填写）
3. **AI 卖点分析**：AI 自动提炼 5-8 个核心卖点并分类，给出额外卖点建议（可点击添加），支持上传图片/文件提取卖点
4. **参数设置**：选择话术风格、字数、闭环时间，AI 推荐选项独立展示
5. **AI 生成话术**：单模型流式生成或多模型交叉对比（实时进度 + AI 评分推荐）
6. **违禁词检测**：两阶段检测（本地扫描 + AI 语境分析），违禁词标红删除线、替换词标绿，支持手动添加
7. **终版输出**：统计、编辑、5种格式下载、自定义文件名、保存到历史记录

## 三、存储说明

使用浏览器 **localStorage** 存储：

**话术历史记录**：产品名称、产品信息、核心卖点、话术风格、字数、闭环时间、生成话术、终版话术、违禁词检测结果、创建/更新时间

**自定义违禁词**：用户手动添加或通过文件导入的违禁词及替换方案

数据可保存、可持久化、关闭浏览器后重新打开仍可查看。支持增删改查。

## 四、AI 使用说明

### AI 在各环节的使用方式

| 环节 | AI 模型 | 使用方式 |
|------|---------|---------|
| 产品信息检查（Step 1） | DeepSeek V3 | 检查信息完整性，缺失信息生成交互式追问 + 可点击建议 |
| 图片识别（Step 1） | Qwen3 VL Plus（多模态） | 识别产品图片，生成结构化产品信息 |
| 文件分析（Step 1/2） | DeepSeek V3 | 从文档中提取产品信息或卖点 |
| 卖点分析（Step 2） | DeepSeek V3 | 分析产品信息，提炼卖点，推荐参数 |
| 单模型话术生成（Step 4） | Claude 4.6 Sonnet | 基于 AIDA/FABE 方法论流式生成话术 |
| 多模型交叉对比（Step 4） | Claude 4.6 + DeepSeek V3 + Qwen3 235B | 三模型并行生成，AI 评分推荐 |
| 话术评分（Step 4） | DeepSeek V3 | 6维度评分（吸引力/说服力/感染力/促单/流畅度/字数） |
| 违禁词语境分析（Step 5） | DeepSeek V3 | 理解上下文，排除误判 |
| 文件违禁词提取（违禁词库页） | DeepSeek V3 | 从上传文件中自动识别违禁词 |
| 代码开发 | Cursor + Claude | 全部代码由 AI 辅助开发 |

### 话术核心方法论

**AIDA 模型（话术主结构）**：
1. **开场痛点（Attention）**：场景话术 + 停留话术
2. **品牌背书 + 引出产品（Interest）**：优势话术 + 品牌加持化
3. **主卖点展示 + 竞品对比（Desire）**：FABE 原则 + 痛点场景化 + 卖点利他化
4. **首次促单 + 售后保障（Action）**：促单四大心理 + 性价比话术
5. **感情升华 + 应用场景**：共情话术 + 价值话术
6. **二次促单 + 收尾**：促销成单话术

> 以上方法论来源于直播营销团队 2024 年度述职 PPT 中的实战总结。

### 违禁词库

内置 **130+ 个**抖音直播违禁词，分为 **7 大类**，支持用户自定义扩展（手动添加或导入文件 AI 识别）。

## 六、项目结构

```
src/
├── app/
│   ├── page.tsx                    # 首页（Hero + 演示动画 + 功能介绍）
│   ├── generate/page.tsx           # 话术生成主页面（6步流程）
│   ├── history/page.tsx            # 历史记录列表
│   ├── history/[id]/page.tsx       # 话术详情页（可编辑）
│   ├── forbidden-words/page.tsx    # 违禁词库（浏览 + 添加 + 导入）
│   └── api/                        # 服务端 API（备用）
├── components/
│   ├── navbar.tsx                  # 顶部导航栏
│   ├── demo-animation.tsx          # 首页演示动画组件
│   └── steps/                     # 6个步骤组件
│       ├── step-input.tsx          # Step 1: 产品信息输入 + 图片上传 + AI信息检查
│       ├── step-analyze.tsx        # Step 2: AI 卖点分析 + 上传提取卖点
│       ├── step-params.tsx         # Step 3: 参数设置 + AI推荐
│       ├── step-generate.tsx       # Step 4: AI 话术生成 + 多模型对比 + AI评分
│       ├── step-forbidden.tsx      # Step 5: 智能违禁词检测 + 手动添加
│       └── step-final.tsx          # Step 6: 终版输出 + 5格式下载
└── lib/
    ├── ai-client.ts               # 浏览器端 AI 调用封装
    ├── utils.ts                    # 工具函数
    ├── storage.ts                  # localStorage 存储层
    ├── supabase.ts                 # Supabase 客户端（可选）
    ├── script-templates.ts         # 话术结构模板 + 方法论 + 类目模板
    └── forbidden-words-data.ts     # 违禁词库数据（130+条）
```
