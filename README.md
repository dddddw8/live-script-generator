# 直播话术智能生成器

> AI 驱动的直播带货话术生成工具，输入产品信息即可自动生成符合「痛点→背书→卖点→促单」结构的专业直播话术，内置违禁词检测与替换。

## 一、项目简介

### 解决什么问题

直播运营人员在日常工作中，**单品话术撰写耗时 1-2 小时**，且容易触碰平台违禁词导致直播间被处罚。本工具将话术撰写时间缩短至 **5-10 分钟**，并自动检测违禁词，大幅提升工作效率和合规安全性。

### 核心功能

1. **6步话术生成流程**：产品信息输入 → AI卖点分析 → 参数设置 → AI话术生成 → 违禁词检测替换 → 终版输出
2. **多模型交叉对比**：Claude 4.6 Sonnet + DeepSeek V3 + Qwen3 235B 三个模型同时生成话术，选最优版本
3. **违禁词检测与替换**：内置 130+ 抖音违禁词库（7大类），自动标红违禁词、标绿替换词，支持用户修改
4. **图片智能识别**：上传产品图片，AI（Qwen3 多模态模型）自动识别产品信息和卖点
5. **话术方法论**：内置 AIDA 模型、FABE 卖点原则、促单四大心理、话术品牌化三要素、十大话术类型等实战方法论
6. **灵活参数配置**：支持 4 种话术风格（知识科普/情感共鸣/促销逼单/品牌种草）、3 档字数、3 档闭环时间
7. **历史记录管理**：所有生成的话术自动保存到 localStorage，支持搜索、编辑、下载

### 使用流程

1. **输入产品信息**：选择产品类目（快捷填充模板），输入产品详情，可上传产品图片让 AI 自动识别
2. **AI 卖点分析**：AI 自动分析产品信息，提炼 5-8 个核心卖点（分为功能/情感/价格/信任四类），给出参数推荐
3. **参数设置**：选择话术风格、字数、闭环时间
4. **AI 生成话术**：单模型快速生成或多模型交叉对比，支持流式输出、在线编辑、重新生成
5. **违禁词检测**：自动扫描话术，标记违禁词并推荐替换方案，用户可逐条确认或修改
6. **终版输出**：查看统计、复制全文、下载文件、保存到历史记录

## 三、存储说明

使用浏览器 **localStorage** 存储话术历史记录：

- 每条记录包含：产品名称、产品信息、核心卖点、话术风格、字数、闭环时间、生成话术、终版话术、违禁词检测结果、创建/更新时间

- 支持增删改查：保存新话术、编辑已有话术、删除记录、按关键词搜索

| 环节 | AI 模型 | 使用方式 |
|------|---------|---------|
| 卖点分析（Step 2） | DeepSeek V3（国内节点） | 分析产品信息，自动提炼 5-8 个核心卖点并分类，推荐话术参数 |

### 话术核心方法论

系统内置的话术结构融合了团队实战经验和业界方法论：

**AIDA 模型（话术主结构）**：
1. **开场痛点（Attention）**：场景话术 + 停留话术，引起目标用户注意
2. **品牌背书 + 引出产品（Interest）**：优势话术 + 品牌加持化，建立信任
3. **主卖点展示 + 竞品对比（Desire）**：FABE 原则 + 痛点场景化 + 卖点利他化
4. **首次促单 + 售后保障（Action）**：促单四大心理（从众/损失恐惧/稀缺/互惠）+ 性价比话术
5. **感情升华 + 应用场景**：共情话术 + 价值话术
6. **二次促单 + 收尾**：促销成单话术，痛点放大 + 品牌保障 + 卖点重复

**FABE 卖点原则**：Feature（特征）→ Advantage（优势）→ Benefit（利益）→ Evidence（证据）

**话术品牌化三要素**：品牌加持化、痛点场景化、卖点利他化

**促单四大心理**：从众心理、损失恐惧、稀缺效应、互惠效应

**十大话术类型**：场景话术、优势话术、共情话术、性价比话术、比价话术、价值话术、停留话术、评论话术、抽奖话术、促销成单话术

> 以上方法论来源于直播营销团队 2024 年度述职 PPT 中的实战总结，经过多场直播验证有效。

### 违禁词库

内置 **130+ 个**抖音直播违禁词，分为 **7 大类**：

| 类别 | 数量 | 示例 |
|------|------|------|
| 绝对化用语 | 40个 | 最好→非常好、第一→领先、唯一→少有 |
| 虚假承诺 | 21个 | 假一赔十→正品保障、立竿见影→使用感受明显 |
| 医疗功效 | 28个 | 治疗→有助于改善、减肥→体重管理 |
| 导流违规 | 12个 | 加微信→关注店铺、私聊下单→点击购物车下单 |
| 低俗歧视 | 7个 | 相关词汇→合规表述 |
| 虚假营销 | 12个 | 手慢无→抓紧时间、买到就是赚到→非常划算 |
| 虚假宣称 | 10个 | 央视推荐→媒体关注、专家推荐→专业认可 |

```
│   └── api/                        # 服务端 API（备用）
│       ├── generate/route.ts
│       ├── generate-multi/route.ts
│       ├── analyze/route.ts
│       ├── analyze-image/route.ts
│       └── check-forbidden/route.ts
├── components/
│   ├── navbar.tsx                  # 顶部导航栏
│   └── steps/                     # 6个步骤组件
│       ├── step-input.tsx          # Step 1: 产品信息输入 + 图片上传
│       ├── step-analyze.tsx        # Step 2: AI 卖点分析
│       ├── step-params.tsx         # Step 3: 参数设置
│       ├── step-generate.tsx       # Step 4: AI 话术生成 + 多模型对比
│       ├── step-forbidden.tsx      # Step 5: 违禁词检测与替换
│       └── step-final.tsx          # Step 6: 终版输出与保存
└── lib/
    ├── ai-client.ts               # 浏览器端 AI 调用封装（streamChat/chatCompletion/visionChat）
    ├── utils.ts                    # 工具函数
    ├── storage.ts                  # localStorage 存储层
    ├── supabase.ts                 # Supabase 客户端（可选）
    ├── script-templates.ts         # 话术结构模板 + 方法论 + 类目模板
    └── forbidden-words-data.ts     # 违禁词库数据（130+条）
```
